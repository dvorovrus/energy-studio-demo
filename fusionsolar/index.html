Подключить мою JK-BMS

Данные поступают с твоего ESP32 через локальный мост только для чтения. Инвертором и Sonoff этот интерфейс не управляет.

Открой панель ESP32 → Настройки → ключи для Android/Windows. Используй сохранённый ключ или свободный слот: перевыпуск ключа отключит старый клиент этого слота. Ключ хранится только в памяти локального сервера. Соединение PC → ESP32 использует обычный HTTP внутри домашней сети.
Ключ пока не установлен. Интерфейс работает в деморежиме.
